    - Implement CaosMIDISlaveSync
        - Slave clock
            - API
                - .attachSlaveSync(device)
                - .detachSlaveSync
            - CaosMIDISlaveSync

                - .randomTime is turned off and restored on detach
            - CaosSequencer.externalClock avoids overwriting the external tempo
    - Tests

        - 627 assertions

- ### v2.7.3
     MIDI
        - Master clock
            - API
                - .attachMasterSync(device)
                - .detachMasterSync(device)
            - CaosMIDIClock
                - Sends 24 ppqn following TempoClock
                - Continuous clock while attached; Start/Stop/Continue
                  control the external transport
                - Ticks scheduled in absolute beats, without drift
                - Several destinations; detach/free sends Stop
            - CaosBox.play / pause / stop send Start / Stop / Continue
    - Bugfixes:
        - Re-evaluating a CaosGear instrument now updates the keyboard
          control on the next note, not on the next sequencer step
        - A clock attached during pause sends Start on resume if it never received Start/Continue
        - .attachOut, .attachIn and their detach accept a CaosInstrument and resolve its track
    - Tests
        - 619 assertions

- ### v2.7.2
    - MIDI
        - Keyboard input for melodic tracks
            - API
                - .attachIn(track, device, channel)
                - .detachIn(track)
            - CaosMIDITrackIn
                - Monophonic
                - Plays the assigned CaosInstrument voice-track
                - The sequencer keeps advancing while active 
                - Triggers with no active steps
                - Uses track's audio mute/solo
                - Velocity scales amp/amp1/amp2 for that note only
                - One-shot envelopes: note-off keeps the tail
            - .panic releases held keys; .free releases the MIDIdefs
    - GUI
        - Random accent color in sequence
            - .color.randomColor(true/false), ..random stays as alias
                - Changes the accent every 0.5, 1, 2 or 4 beats
            - Follows TempoClock.default, so BPM and random time apply
    - Tests
        - 583 assertions
