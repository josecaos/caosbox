# v2.1.2 — Fix: argumentos de `CaosBass2`

> **Rama:** `dev-v2.0` · **Estado:** aplicado en el árbol de trabajo.
> **Verificación:** SynthDefs construidos headless + `.scd` + 177 aserciones.

---

## 1. El bug

El SynthDef `\bajodos` llamaba a `CaosBass2.ar(...)` **por posición, sin `pan`**:

```supercollider
// antes
CaosBass2.ar(att, rel, note, trig, filtminf, filtmaxf, filtime,
             rq, bandw, iphase, gate, amp1, amp2, doneAction)
```

Pero la firma actual de CaosPercLib es:

```supercollider
*ar {|att, rel, note, trig, filtminf, filtmaxf, filtime,
      rq, bandw, iphase, gate, amp1, amp2, pan, doneAction|
```

O sea:

| arg de `CaosBass2` | recibía |
|---|---|
| `amp1` | amp1 ✓ |
| `amp2` | amp2 ✓ |
| **`pan`** | **`doneAction` (2)** ✗ |
| `doneAction` | default 2 (por casualidad) |

Consecuencias: `pan = 2` (fuera de rango) y el `pan:` que manda `CaosGear.bass2`
se ignoraba, porque el SynthDef `\bajodos` tampoco declaraba `pan`.

## 2. Por qué pasó

CaosPercLib agregó `doneAction` a la firma de `CaosBass2` (`ec785d2` → `3d9f998`).
Como la llamada era posicional, todo lo que venía después quedó corrido **sin ningún
error**: los argumentos existen, solo llegan al parámetro equivocado.

## 3. El fix

1. `\bajodos` ahora declara `pan=0` y lo pasa.
2. **Los seis SynthDefs de CaosPercLib pasan a llamadas por nombre** (kwargs):
   `\bajouno`, `\bajodos`, `\ambuno`, `\ambdos`, `\acordesuno`, `\acordesdos`
   (y el `customSignal` del bajo custom).

Con kwargs, si CaosPercLib agrega un argumento, se usa su default; si lo **renombra**, el
SynthDef falla al construirse en vez de sonar mal en silencio. De paso quedó documentado el
mapeo raro de `\ambuno`: su `iphase` es el `phase` de `CaosPad`.

## 4. Verificación

* Los SynthDefs se construyen headless (sin server) sin errores — un kwarg inexistente
  habría lanzado error en la construcción.
* Los 15 `.scd` parsean.
* Suite: **177 aserciones, 0 fallos**.

## 5. Cómo probar

```supercollider
b = CaosGear.new;
b.bass2(50, [36, 38, 41], \seq, pan: -0.8, amp1: 0.3, amp2: 0.3);
b.toTrack([0, 4, 8, 12]);
```
